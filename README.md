# Ray Tracer — Ray Tracing in One Weekend (moje wykonanie)

Krótki projekt będący moją implementacją książki "Ray Tracing in One Weekend" (Peter Shirley). Celem było przepisać i eksperymentować z kodem, zrozumieć podstawy śledzenia promieni (ray tracing) i wygenerować proste obrazy z kulami i różnymi materiałami.

## Wyniki projektu

- Aby zobaczyć wizualizacje efektu końcowego projektu należy otworzyć image.ppm za pomocą dowolnego programu, który radzi sobie z otwieraniem plików PPM.
- Zachęcam też do własnego eksperymentowania. W tym celu należy stworzyć w pliku main obiekty, które ma wygenerować Ray Tracer, a nastepnie przekierować plik wykonywalny do pliku z rozszerzeniem ppm.
```
./plik_wykonywalny > obrazek.ppm
```
